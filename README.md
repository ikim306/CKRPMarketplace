# Central Kansas Roleplay (CKRP) - Official Vehicle Valuation & Marketplace Hub

Welcome to the official repository for the **Central Kansas Roleplay (CKRP)** Vehicle Valuation & Marketplace web app! This application provides players with real-time vehicle valuations based on accurate in-game MSRPs, mileage wear, trade-in factors, and paint customizations, alongside a live marketplace for community listings.

---

## 🌟 Key Features

* **Complete 97-Vehicle Roster**: Features all 72 Standard On-Sale vehicles and 25 Limited/Off-Sale/Emergency vehicles from CKRP.
* **Cascading Vehicle Selector**: Easily filter by Make → Model → Year → Trim.
* **Valuation Engine**: Accurately calculates resale values using:
  * In-game MSRP benchmarks
  * Instant dealer trade-in rates (~69%)
  * Mileage wear depreciation
  * Custom paint wrap bonuses
* **Dynamic Canvas Rendering**: Generates a side-profile canvas illustration painted in your chosen vehicle color.
* **Live Player Marketplace**: Post valuations directly as active listings and browse community trades.

---

## 🚀 Live Demo / Web Preview

To host this project locally or view the preview:

1. Download or copy the `index.html` file from this repository.
2. Open `index.html` directly in any web browser (Google Chrome, Firefox, Safari, Edge).

No backend server, Node.js, or complex installation is required—it runs completely client-side in the browser using Tailwind CSS and HTML5 Canvas.

---

## 🛠️ Built With

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Tailwind CSS** (via CDN for modern responsive UI)
* **FontAwesome 6** (for UI iconography)
* **HTML5 Canvas API** (for dynamic vehicle renders)
